# Artwork still needed

This project intentionally uses only the supplied painted artwork. The following
assets were not supplied and are represented by neutral, functional fallbacks:

- `assets/cat/<state>_<n>.png`: painted calico animation sprite sheet. The hero
  and dashboard use the supplied static sleeping-cat sticker instead.
  The immersive landing page adds breathing, floating z's, a small greeting
  motion and a tap heart. Walking, stretching, washing and independent head/eye
  poses cannot be represented faithfully with the single supplied illustration.
- Six 4:3 painted club covers: Cozy Readers, Fantasy Realms, Page Turners,
  Mindful Reads, Romance Circle, and Sci-Fi Explorers. Club cards use a muted
  parchment gradient with their existing icon until these arrive.
- Covers for *Gone Girl*, *The Silent Patient*, *Sapiens*, *Educated*, *The
  Hobbit*, and *Pride and Prejudice*. They retain the existing CSS-cover fallback.
- High-resolution individual covers (800×1200) for the supplied catalogue.
  The sheet crops are intentionally unsharpened and soft at large display sizes.
- Corrected high-resolution *Project Hail Mary* cover.
- Optional painted icon/logo set.
